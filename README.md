# 机械工程师工作台

给一名机械设计制造及其自动化专业的毕业生用的能力训练工作台。主干是**设计工程**与**制造工艺**，其余九个模块做支撑，目标是用 24 个月把你推到「看得出错」和「定标准带人」。

## 怎么打开

双击 `index.html`，用 Edge 或 Chrome 打开即可。不需要联网、不需要安装任何东西。

三个文件必须放在同一个文件夹里一起移动，缺一个就打不开：

| 文件 | 作用 |
|---|---|
| `index.html` | 界面与样式 |
| `app.js` | 逻辑：闸门、排期、导入导出 |
| `curriculum.js` | 课程数据：11 个模块、128 个知识点 |

## 最重要的一件事：手动闸门

每个知识点都带一道练习。流程是固定的，而且顺序不能反：

1. **先自己写判断。**不查资料、不问 AI，至少写 20 个字，写不出就写「我不确定哪里」。
2. **拆封 AI 对照。**点「拆封 AI 对照」，封条收起，露出该问 AI 的问题、合格线（3 级）、资深线（5 级）和依据。
3. **对照自评。**基本一致 / 部分一致 / 明显不一致，三选一，并写下分歧点。

这个设计的来源是核电站控制室与民航的手动飞行规章：**刻意保留的低效是保险**。当 AI 能瞬间给出教科书答案时，你真正会贬值的能力是「在 AI 关闭的状态下自己做出判断」。

分歧会自动变成最优先的复习项。所以「明显不一致」不是失败，是这个工具最有价值的输出。

## 五个视图

- **今日**：当天该做什么。按到期复习、主干薄弱项、缺证据项自动排出，一天 3–8 项。
- **能力矩阵**：128 个知识点 × 0–5 级。等级不是感觉，是行为：0 未开始 / 1 读得懂 / 2 照着做 / 3 独立做 / 4 看得出错 / 5 定标准带人。
- **24 个月路线**：四个阶段（读得懂 → 照着做 → 看得出错 → 定标准带人），每阶段有准入门槛和毕业门槛，门槛按主干等级实时计算。
- **证据库**：图纸、计算书、拆机报告、失效分析、实习记录都算证据。等级只有挂上证据才算真的。
- **数据与备份**：导出 / 导入 / 导出 Markdown 报告。

## 规则

- **升级要付代价。**升到 3 级以上时，如果没有关联证据，必须在依据栏写清你凭什么，否则不给升。
- **状态用线形表示，不用颜色。**实线=已达标，虚线=待复习，点线（朱红）=有判断分歧，双线=已达 5 级，空白=未开始。这样色盲也能读。
- **复习间隔自动排。**判断一致就拉长间隔（1→3→7→16→35→75 天），部分一致减半，明显不一致第二天重来。

## 数据与备份（重要）

进度存在这台电脑的浏览器里（localStorage），**换电脑、清缓存、重装浏览器都会丢**。

- 工作台会在你超过 14 天没导出时，在「今日」顶部提醒你。
- 「导出进度（JSON）」得到的是完整进度文件，可以在任何一台电脑导入回来。
- 导入时可选合并（保留现有、按时间取新）或覆盖。
- 「导出学习报告（Markdown）」是给人看的版本，可以直接贴进简历或存档，但它不能导入。

建议：每周导出一次，文件丢网盘或 U 盘。

## 想改内容

`curriculum.js` 是纯数据，格式直观：每个知识点有 `id / name / en / why / l3 / l5 / gate / probe / ref`。

- `l3` 是达到 3 级的判定行为，`l5` 是 5 级。
- `gate` 是手动闸门题目，`probe` 是拆封后要问 AI 的对照问题。

改完保存，刷新浏览器即可生效。你学得越深，越应该回来把这些条目改得更狠、更具体。

## 自检

在网址后加 `?selftest=1`（例如 `index.html?selftest=1`）会跑一遍内置自检：数据载入、闸门先锁后开、记录与排期、升级规则、证据、报告导出、导入合并。全绿说明功能正常。自检结束会清空进度，先用导出的备份再跑。

## 想在手机上用／想变成网址

见 [DEPLOY.md](DEPLOY.md)。一句话：项目已备好零依赖静态服务器，`node serve.js` 就能在本地跑起来，再按文档走 Cloud Studio 那几步即可上线。**但要注意进度是按网址隔离的**，换地址前先导出 JSON。
